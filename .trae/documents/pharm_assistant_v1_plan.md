# 药品助手 V1 - 项目计划

> 说明：本文为 V1 初期计划，实际实现已大幅演进（应用名定为「小药箱」，并新增多药箱、星标、服用时间安排、后台预排期通知等）。当前最新功能与版本记录见根目录 `README.md`。

## 1. 项目概述

**项目名称**：药品助手（Medicine Assistant）

**V1 核心功能**：帮助普通用户管理日常药品库存，基于用药计划自动预测药品耗尽时间，库存不足时通过 App 内提示 + 推送通知提醒及时补充。

## 3. 数据模型

### 药品（Medicine）

```json
{
  "id": "1700000000001",
  "name": "阿莫西林",
  "dosagePerTime": 1.0,
  "dosageUnit": "片",
  "timesPerDay": 3,
  "currentStock": 20.0,
  "alertThreshold": 3,
  "createdAt": "2026-08-12T10:00:00",
  "updatedAt": "2026-08-12T10:00:00",
  "notes": "饭后服用"
}
```

### 存储方案

- 数据存储在应用文档目录下的 `medicines.json` 文件中
- 文件内容为一个 JSON 数组，包含所有药品对象
- 启动时读取 JSON 文件反序列化为 `List<Medicine>`
- 每次增/删/改操作后全量写回 JSON 文件
- 个人用药数量少（通常 < 10 种），全量读写性能完全足够

### 计算逻辑

- **每日消耗量** = `dosagePerTime × timesPerDay`
- **剩余天数** = `currentStock / 每日消耗量`
- **是否需要提醒** = `剩余天数 < alertThreshold`

## 4. 功能模块

### 4.1 首页 - 药品列表
- 展示用户添加的所有药品卡片
- 每张卡片显示：药品名称、剩余天数、库存数量
- 库存不足的药品（剩余天数 < 阈值）高亮/标记醒目标识
- 空状态引导：无药品时引导用户添加

### 4.2 添加/编辑药品
- 表单字段：
  - 药品名称（必填）
  - 每次剂量（必填，数字）
  - 剂量单位（必填，下拉选择：片/粒/包/ml/滴）
  - 每日次数（必填，数字）
  - 当前库存（必填，数字）
  - 提醒阈值天数（必填，数字，默认值可设为 7）
  - 备注（选填）
- 编辑时预填现有数据

### 4.3 药品详情
- 展示药品完整信息
- 编辑按钮
- 删除按钮（需确认弹窗）

### 4.4 库存快速调整
- 在药品卡片上可直接"+1"或"-1"手动调整库存
- 或直接编辑库存数量

### 4.5 提醒通知
- **App 内提醒**：首页库存不足药品卡片高亮，使用醒目的视觉标识（如红色边框/标签）
- **推送通知**：使用 `flutter_local_notifications` 在后台定时检查，当某药品剩余天数低于阈值时推送通知
  - 检查频率：每日一次（可在应用启动时和后台定时触发）
  - 通知内容示例："[药品名称] 仅剩 3 天用量，请及时配药"

## 6. 技术方案

### 6.1 项目结构

```
pharm_assistant/
├── lib/
│   ├── main.dart                         // 入口，初始化通知和存储
│   ├── app.dart                          // MaterialApp 配置
│   ├── models/
│   │   └── medicine.dart                 // 药品数据模型
│   ├── services/
│   │   ├── storage_service.dart          // JSON 文件读写服务
│   │   └── notification_service.dart      // 推送通知服务
│   ├── screens/
│   │   ├── home_screen.dart              // 首页
│   │   ├── add_edit_medicine_screen.dart  // 添加/编辑药品
│   │   └── medicine_detail_screen.dart   // 药品详情
│   └── widgets/
│       ├── medicine_card.dart            // 药品卡片组件
│       └── empty_state.dart              // 空状态组件
├── pubspec.yaml
└── ...
```

### 6.2 依赖

| 包名 | 用途 | 版本 |
|------|------|------|
| `path_provider` | 获取应用文档目录路径 | latest |
| `flutter_local_notifications` | 本地推送通知 | latest |
| `provider` | 状态管理 | latest |
| `intl` | 日期格式化 | latest |

> 不再依赖 `sqflite`、`path`、`uuid`。ID 使用时间戳毫秒生成，JSON 序列化使用 `dart:convert` 内置库。

### 6.3 状态管理
- 使用 `provider` 进行轻量级状态管理
- 首页药品列表通过 `ChangeNotifierProvider` 管理

### 6.4 通知方案
- 应用启动时初始化通知插件
- 在首页加载完成后检查所有药品，触发条件满足的推送通知
- 使用 `flutter_local_notifications` 的 `periodicallyShow` 或配合 `workmanager` 实现后台定时检查
